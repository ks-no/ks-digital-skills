# Engelsk smitte

Norsk skrevet med engelsk tankegang bak. Ordene er norske og stavet riktig, men
setningen er en oversettelse. Dette er den største feilgruppen i tekst fra
språkmodeller, og den ingen stavekontroll fanger.

Testen er alltid den samme: ville en som kan norsk, og som ikke hadde sett den
engelske setningen, sagt det slik?

## 3. Grammatisk smitte

Mønstre der engelsk grammatikk er kopiert inn i norsk.

**`deres` for `sin`.** Engelsk har bare *their*. Norsk skiller mellom eierens eget
og andres.
✗ `Kommunen sendte deres søknad.` → ✓ `Kommunen sendte sin søknad` / `søknaden
sin` (kommunens egen) eller `deres søknad` (noen andres).

**Foranstilt eiendomsord.** Engelsk *your account*; norsk `kontoen din`.
✗ `Sjekk din innboks.` → ✓ `Sjekk innboksen din.`

**Artikkel foran yrke og rolle.** Engelsk *she is a developer*; norsk `hun er
utvikler`. ✗ `Han er en produkteier.` → ✓ `Han er produkteier.`

**Komparativ og superlativ.** Engelsk bruker superlativ av to; norsk komparativ.
✗ `den beste av de to løsningene` → ✓ `den beste løsningen` (om flere) / `den
bedre av de to`.

**Preposisjoner.** ✗ `kommentere på` → ✓ `kommentere`. ✗ `diskutere om` → ✓
`diskutere`. ✗ `fokusere rundt` → ✓ `konsentrere seg om`. ✗ `påvirke på` → ✓
`påvirke`. ✗ `i forhold til` som universalpreposisjon → ✓ `om`, `for`, `når det
gjelder` (`i forhold til` betyr «sammenlignet med»).

**Passiv og substantivsyke.** Engelsk fagprosa tåler mer passiv enn norsk.
✗ `Valideringen av skjemaet gjøres av tjenesten.` → ✓ `Tjenesten validerer
skjemaet.` Se klarsprak.md.

**Løsrevne leddsetninger og innskudd.** Engelsk stabler innskudd; norsk deler
opp. ✗ `Løsningen, som ble utviklet i 2024 og som nå brukes av 120 kommuner, som
alle har …` → del i to eller tre setninger.

**Verbet på feil plass etter innledende ledd.** Norsk har verbet på andreplass.
✗ `I dag, vi lanserer …` → ✓ `I dag lanserer vi …`

**Engelsk ordstilling i spørsmål og nektelser i leddsetninger.** ✗ `… fordi
brukeren har ikke tilgang` → ✓ `… fordi brukeren ikke har tilgang`.

## 4. Engelsk tegnsetting og typografi

| Engelsk | Norsk |
| --- | --- |
| lang bindestrek (U+2014) | bindestrek med mellomrom (` - `), komma eller kolon; `–` bare i intervaller |
| "sitat" | «sitat» |
| Oxford-komma: `a, b, og c` | `a, b og c` |
| `Ola's` | `Olas` |
| `1,000` og `3.5` | `1 000` og `3,5` |
| `25%` | `25 %` |
| `10/16/2026`, `2026-10-16` i prosa | `16. oktober 2026`, `16.10.2026` |
| `9am`, `9 AM` | `kl. 9`, `kl. 09.00` |
| Title Case I Overskrifter | Bare første ord stor |
| `e.g.`, `i.e.`, `etc.` | `f.eks.`, `dvs.`, `osv.` |
| kolon før liste med stor forbokstav i punktene | liten forbokstav hvis punktene fortsetter setningen |

## 5. Ord som er greie, ikke overrett

Noen engelske ord er etablert norsk fagspråk, særlig til utviklere. Ikke bytt dem ut
mekanisk. Vurder mottaker.

- Til utviklere: `backend`, `frontend`, `deploy`, `commit`, `pull request`, `merge`,
  `branch`, `workflow`, `push`, `rebase`, `squash`, `secret`, `token`, `endepunkt`,
  `container`, `pipeline` kan stå, bøyd på norsk (`merget`, `deployes`, `branchen`).
  Ikke oversett dem til `flette`, `gren`, `arbeidsflyt` eller `utrulling`. Se
  «Utviklerord» i ordliste.md.
- Til kommuner og ledelse: skriv `tjener/baksystem`, `brukergrensesnitt`, `sette i
  drift`, `endring`, `tilgangsnøkkel`, og forklar ordet første gang hvis det må
  stå på engelsk.
- `e-post` (ikke `epost`, `mail` eller `e-mail`), `nettside` (ikke `webside`),
  `app` eller `program` (ikke `applikasjon` når det ikke trengs), `KI` i formell
  tekst.
